# WFCDungeon plugin

This directory contains the optional Unreal Engine integration for JSON produced by the project's `wfc_dungeon` CLI. The plugin and editor were not built or exercised during the overhaul; the CPU application's build does not validate the editor integration. The original project targeted Unreal Engine 5.7, and compatibility with other versions is not established here.

## Intended workflow

Copy `WFCDungeon/` into an Unreal project's `Plugins/` directory, regenerate the project's IDE files and build its editor target. Enable the plugin, create a `TileMappingDataAsset`, assign tile meshes and attach it to a dungeon generator actor with the desired JSON path. The exposed `Generate From Json` and `Clear Generated` actions drive the original editor workflow.

The JSON producer is an optional CMake target enabled with `-DBUILD_DUNGEON=ON`. Its options are exposed by `wfc_dungeon --help`. The plugin implementation and original integration notes are in [WFCDungeon](WFCDungeon/) and [docs/ue5_integration.md](../docs/ue5_integration.md).

## Validation boundary

Current CPU tests and timings are documented in [docs/results.md](../docs/results.md). They do not measure editor rendering, navigation rebuilding, asset compatibility or level quality. The screenshots in the historical documentation remain examples from the earlier project, not output generated by this audit.
