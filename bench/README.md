# CPU measurement entry point

`BUILD_DIR=build PYTHON=python3 bash bench/run.sh` invokes the already-built benchmark executable. It does not configure or rebuild the application. Install Linux build prerequisites and create a Release build with OpenMP enabled first.

The protocol is fixed in `collect.py`: a binary sample, tile size 2, sizes 64 and 128, serial plus OpenMP at 1/2/4/8 threads, one warm-up seed 41 and five measured seeds 42 through 46. CPU affinity and OpenMP settings are recorded with the original CSV and process output. A failed measured solve is retained and stops aggregation. [Detailed boundaries](../docs/results.md).

Default outputs go to the ignored `results/local/` directory under `bench/`. Pass a separate output path as the first argument to save a reviewed snapshot. The recorded collection used `BUILD_DIR=build-wsl PYTHON=python3 bash bench/run.sh bench/results/2026-09-12` from the repository root.

After installing the pinned plotting requirements, `python bench/plot.py` regenerates the committed light/dark SVGs. This only reads the CSV summary; it does not run a solver. Historical figures under `docs/figures/` and `rapport/` are retained separately and are not generated by this plotter.
