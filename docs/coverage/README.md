# Historical coverage report

The HTML files in this directory are a retained generated report from the original project. They were not regenerated or validated during the repository overhaul. Their percentages describe that earlier report and must not be read as current coverage measurements.

The current validation consists of the thirteen passing CPU CTest suites documented in [TESTING.md](../TESTING.md). No new line or branch coverage percentage is claimed. The [historical report entry page](index.html) is kept for provenance.
